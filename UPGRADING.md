# Upgrading

This repository is a template, so adopters own their application code after cloning it. Treat future template releases as upstream examples rather than automatic migrations.

Pull upstream changes most often from:

- `bin/`
- `config/`
- `.github/`
- `package.json`
- `Gemfile`

Review application-specific changes under `app/` before applying them to an adopted app.

Initial release notes will be added when the Tier 1 starter is tagged.
